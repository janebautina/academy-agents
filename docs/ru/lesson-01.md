# Урок 1. Устав компании и первый сотрудник — агент-секретарь

**Что получится к концу урока:** у вашей компании появится устав, который читают все агенты, и первый сотрудник. Каждое утро секретарь сам присылает вам в Telegram сводку: три главных дела на сегодня, что нового у вас и у конкурентов, что ждёт вашего решения.

**Сколько времени:** 40–60 минут в первый раз. Дальше 0 минут: секретарь работает сам.
**Сколько стоит:** одна сводка — меньше 10 копеек. За месяц выходит меньше 5 ₽.
**Что нужно уметь:** ничего. Мы пройдём каждый шаг, включая установку программ.

## 1. Что такое компания из агентов

Обычная компания: владелец и сотрудники. У каждого сотрудника своя работа, свои права (что можно решать самому, а что только с разрешения начальника) и правила компании.

Компания из агентов устроена так же, только сотрудники — программы.

| В обычной компании | В компании из агентов | Где лежит |
|---|---|---|
| Устав, регламенты | Файл устава, его читает каждый агент | `company/COMPANY.md` |
| Сотрудник | Агент: программа + инструкция | `agents/<имя>/` |
| Должностная инструкция | Промпт агента: что делать и чего нельзя | `agents/<имя>/prompt.ru.md` |
| Мозг сотрудника | Нейросеть (DeepSeek, YandexGPT, ChatGPT) | настройка в `.env` |
| Отчёт начальнику | Сообщение в Telegram | — |
| Журнал работ | Журнал компании: каждое действие агента | `company/journal.md` |
| Подпись начальника | «Да» владельца на всё рискованное | правила в уставе |

Три правила, на которых держится вся компания:

1. **Устав главнее всего.** Хотите, чтобы агенты вели себя иначе, — меняйте устав, а не код.
2. **Всё рискованное — только с вашего «да».** Деньги, публикации, письма незнакомым людям, удаление. Агент готовит, вы нажимаете.
3. **Всё записывается.** Каждый агент пишет в журнал, что сделал. Вы всегда можете проверить.

Первый сотрудник — секретарь. Он ничего не отправляет наружу и ничего не тратит, только читает и сообщает вам. Поэтому с него безопасно начинать.

## 2. Подготовка компьютера

Нужна одна программа — **Python** (язык, на котором написаны агенты) — и **терминал**: окно, куда пишут команды.

### Mac

1. Откройте **Терминал**: нажмите `Cmd + Пробел`, напишите «Терминал», нажмите Enter.
2. Напишите и нажмите Enter:
   ```
   python3 --version
   ```
3. Если видите `Python 3.9` или новее — всё готово, переходите к шагу 3.
   Если Mac предложит установить «инструменты командной строки» — нажмите «Установить» и дождитесь конца, затем повторите команду.

### Windows

1. Откройте https://www.python.org/downloads/ и нажмите жёлтую кнопку **Download Python**.
2. Запустите скачанный файл. **Важно:** внизу первого окна поставьте галочку **Add python.exe to PATH**. Потом **Install Now**.
3. Откройте **PowerShell**: меню Пуск › напишите «PowerShell» › Enter.
4. Напишите:
   ```
   py --version
   ```
   Должно появиться `Python 3.12` или новее.

> **На Windows везде, где в уроке написано `python3`, пишите `py`.**

### Три команды терминала, которых хватит на весь курс

| Команда | Что делает |
|---|---|
| `cd папка` | перейти в папку (`cd ..` — на уровень выше) |
| `ls` (Mac) / `dir` (Windows) | показать файлы в папке |
| стрелка ↑ | повторить прошлую команду |

## 4. Ключ нейросети

Агенту нужен «мозг» — нейросеть. Программа общается с ней через **API**: это та же переписка, что в чате, только её ведёт программа. Чтобы нейросеть знала, кто спрашивает и с кого брать деньги, нужен **API-ключ** — длинный пароль вида `sk-...`.

Платите вы за каждый запрос, по копейкам. Подписка на ChatGPT для API не подходит, баланс пополняется отдельно.

### Вариант 1. DeepSeek (дёшево, используем в уроках)
1. https://platform.deepseek.com › войти (почта или Google).
2. **Top up** › пополнить на $2–5. Из России напрямую карты РФ обычно не проходят; можно через cloud.ru (DeepSeek в рублях) или вариант 2.
3. **API keys** › **Create new API key** › название `my-company` › **Copy**. Ключ показывают один раз.

### Вариант 2. YandexGPT (оплата в рублях)
1. https://console.yandex.cloud › войти с Яндекс ID › создать платёжный аккаунт › открыть сервис **AI Studio**. (Подробная инструкция со скриншотами — в видео урока.)
2. Создайте сервисный аккаунт с ролью `ai.languageModels.user` и API-ключ для него.
3. Запишите **идентификатор каталога** (folder id) — строка вида `b1g...`.

### Записать ключ в настройки
1. В папке `my-company` сделайте копию файла `.env.example` и назовите её `.env` (с точкой в начале).
   - Mac: в терминале `cp .env.example .env`, потом `open -e .env`.
   - Windows: `copy .env.example .env`, потом `notepad .env`.
2. Вставьте ключ после `LLM_API_KEY=` без пробелов и кавычек:
   ```
   LLM_API_KEY=sk-ваш-ключ
   ```
3. Для YandexGPT замените три строки:
   ```
   LLM_BASE_URL=https://llm.api.cloud.yandex.net/v1
   LLM_MODEL=gpt://b1gваш-каталог/yandexgpt/latest
   LLM_FOLDER_ID=b1gваш-каталог
   ```
4. Сохраните файл.

> **Безопасность.** Файл `.env` — как ключи от сейфа. Никому не отправляйте, не выкладывайте в интернет и не вставляйте в чаты. Он уже в списке исключений `.gitignore`, поэтому на GitHub не попадёт. Если ключ утёк — удалите его на сайте и создайте новый.

## 5. Устав вашей компании

Это главный шаг урока. Агенты будут делать то, что написано в уставе. Напишете размыто — получите размытую работу.

1. Скопируйте `templates/COMPANY-template.md` поверх `company/COMPANY.md` (там сейчас устав нашей школы — оставьте его как образец в другом файле, если хотите).
2. Заполните шесть разделов. Подсказки — прямо в файле.

### Как написать хороший устав: три примера

**Кофейня**
- Кто мы: «Кофейня у метро, 2 бариста и я. Средний чек 450 ₽. Гости — офисы и жители района. ВК, Telegram, Яндекс Карты».
- Цель: «Ответ на каждый отзыв за сутки. Освободить мне 10 часов в неделю».
- Только с «да»: «ответы на негативные отзывы, любые скидки, заказ у поставщиков».

**Интернет-магазин на маркетплейсе**
- Кто мы: «Продаю домашний текстиль на Wildberries и Ozon, 140 товаров, работаю один, склад у фулфилмента».
- Цель: «Рейтинг 4,8+. Новые карточки за 1 день вместо 3».
- Только с «да»: «изменение цен, акции, ответы на претензии».

**Услуги (репетитор, юрист, мастер)**
- Кто мы: «Репетитор по английскому, 18 учеников, занятия онлайн, 2 000 ₽ за час».
- Цель: «Заполнить 6 свободных окон. Не терять заявки из мессенджеров».
- Только с «да»: «изменение цены, перенос занятий, любые обещания результата».

### Проверьте себя
- [ ] Новый человек поймёт по уставу, чем вы занимаетесь?
- [ ] В целях есть цифры?
- [ ] Для каждого агента понятно, что он может сам, а что только с вашего «да»?
- [ ] Деньги и публикации — только с «да»?

## 6. Задачи и ленты

### `company/tasks.md` — ваши задачи
Одна задача — одна строка. Срок в конце. Сделали — `[x]`.
```
- [ ] Ответить поставщику про новую цену — до 2026-11-12
- [ ] Выложить фото нового меню — до 2026-11-10
- [x] Продлить аренду
```
Секретарь сам решит, что важнее сегодня: просроченное и с ближайшим сроком — первым.

### `company/sources.txt` — за чем следить
Одна строка: название, пробел, ссылка на ленту (RSS).
```
Мой-канал https://www.youtube.com/feeds/videos.xml?channel_id=UC...
Конкурент https://www.youtube.com/feeds/videos.xml?channel_id=UC...
Новости-отрасли https://habr.com/ru/rss/hub/artificial_intelligence/articles/
```
Где взять ссылку:
- **YouTube-канал:** откройте канал › «Подробнее» › «Поделиться каналом» › «Копировать идентификатор канала». Подставьте его после `channel_id=`.
- **Сайт или блог:** часто есть значок RSS или адрес `/feed`, `/rss`.
- **Telegram-канал:** через сервисы вроде rss-bridge (ссылка вида `.../?action=display&bridge=TelegramBridge&username=имя_канала&format=Atom`).

Агент знает только то, что ему дали. Сравните сводку с данными из шага 1:
- цифры совпадают?
- нет ли событий, которых не было в данных?

## 8. Как устроен код: разбор построчно

Читать код не обязательно, агент работает и так. Но когда вы понимаете, что происходит, вы можете менять его сами (или попросить агента-программиста из урока 2).

### Общая схема
```
устав + задачи + ленты + журнал  ──►  инструкция секретаря  ──►  нейросеть  ──►  сводка
                                                                                  ├─► экран
                                                                                  ├─► файл в reports/
                                                                                  ├─► Telegram
                                                                                  └─► строка в журнале
```

### `agents/secretary/run.py` — работа секретаря

```python
def build_input() -> str:
    charter = (ROOT / "company" / "COMPANY.md").read_text(encoding="utf-8")
```
Функция `build_input` собирает всё, что секретарь должен прочитать. Первая строка открывает устав и читает его целиком в переменную `charter`.

```python
    return (
        f"Сегодня / Today: {date.today():%Y-%m-%d}\n\n"
        f"=== УСТАВ / CHARTER ===\n{charter}\n\n"
        f"=== ЗАДАЧИ / TASKS ===\n{sources.tasks()}\n\n"
        ...
    )
```
Склеиваем один большой текст: сегодняшняя дата (иначе нейросеть не знает, что «до 10 ноября» — это завтра), устав, задачи, ленты, журнал. Заголовки `=== ... ===` помогают нейросети понять, где что.

```python
def main() -> None:
    env.load()
```
Читаем настройки из файла `.env`: ключ, модель, Telegram.

```python
    lang = env.get("COMPANY_LANGUAGE", "ru")
    instructions = (HERE / f"prompt.{lang}.md").read_text(encoding="utf-8")
```
Берём инструкцию секретаря на нужном языке: `prompt.ru.md` или `prompt.en.md`. Это его «должностная инструкция».

```python
    if "--dry-run" in sys.argv:
        print(data)
        return
```
Если запустили с `--dry-run`, просто печатаем собранные данные и выходим. Нейросеть не вызывается, денег не тратится.

```python
    summary = llm.chat(instructions, data)
```
Главная строка. Отправляем нейросети инструкцию и данные, получаем сводку.

```python
    out = reports / f"{date.today():%Y-%m-%d}-secretary.md"
    out.write_text(summary + "\n", encoding="utf-8")
```
Сохраняем сводку в файл с датой в имени — получается архив всех сводок.

```python
    if telegram.configured():
        telegram.send(summary)
```
Если Telegram настроен — отправляем вам. Если нет — сводка остаётся на экране и в файле.

```python
    journal.write("Секретарь", f"утренняя сводка › {where}")
```
Записываем в журнал компании, что сделали.

### `core/llm.py` — разговор с нейросетью

```python
    body = {
        "model": env.need("LLM_MODEL"),
        "messages": [{"role": "system", "content": system}, {"role": "user", "content": user}],
        "max_tokens": max_tokens,
        "temperature": 0,
    }
```
Письмо нейросети:
- `model` — какая модель отвечает (из `.env`);
- `messages` — два сообщения: `system` — инструкция («кто ты и что делать»), `user` — данные;
- `max_tokens` — максимальная длина ответа (токен ≈ полслова), чтобы случайно не потратить много;
- `temperature: 0` — никакой фантазии. Для сводок и цифр нужна точность. Для творческих задач (посты) ставят 0,7–1.

```python
    headers = {"Authorization": f"Bearer {env.need('LLM_API_KEY')}", ...}
```
К письму прикладываем ключ — так нейросеть знает, с чьего баланса списать деньги.

```python
    request = urllib.request.Request(f"{base}/chat/completions", ...)
```
Отправляем письмо по адресу `.../chat/completions`. Этот адрес одинаковый у DeepSeek, OpenAI, YandexGPT и десятков других — поэтому нейросеть меняется одной строкой в `.env`, а код остаётся прежним.

```python
    except urllib.error.HTTPError as e:
        hint = {401: "the key is wrong", 402: "the balance is empty, top it up", 429: "too many requests, wait a minute"}
```
Если что-то пошло не так — объясняем человеческими словами: 401 — неверный ключ, 402 — кончились деньги, 429 — слишком часто.

### `agents/secretary/sources.py` — что читает секретарь
- `tasks()` — открывает `company/tasks.md`.
- `feeds()` — для каждой строки из `sources.txt` скачивает ленту и берёт записи за последние 2 дня. Если одна лента сломалась, сводка всё равно соберётся — просто с пометкой «не удалось прочитать».
- `recent_journal()` — последние 15 строк журнала.

Хотите, чтобы секретарь читал что-то ещё (таблицу продаж, почту, CRM) — добавляется новая функция здесь и одна строка в `build_input`. Этим займёмся в следующих уроках.

### `agents/secretary/prompt.ru.md` — инструкция
Обычный текст. Меняйте его как угодно: «добавь погоду», «пиши короче», «главное — заказы с маркетплейса». Код трогать не нужно.

## 9. Сводка в Telegram

1. В Telegram найдите **@BotFather** (с синей галочкой) › **Start** › отправьте `/newbot`.
2. Имя бота: например, «Секретарь Кофейни». Адрес: латиницей, в конце `bot`, например `coffee_secretary_bot`.
3. BotFather пришлёт **токен** вида `7712345678:AAH...`. Это пароль бота — храните как API-ключ.
4. Вставьте в `.env`:
   ```
   TELEGRAM_BOT_TOKEN=7712345678:AAH...
   ```
5. Откройте своего бота в Telegram и напишите ему что угодно, например «привет».
6. В терминале:
   ```
   python3 -m core.telegram
   ```
   Появится строка `TELEGRAM_CHAT_ID=123456789 (ваше имя)`. Скопируйте её в `.env`.
7. Запустите секретаря ещё раз — сводка придёт в Telegram.

## 10. Каждое утро само: расписание

Выберите один вариант.

### Вариант А. Mac (компьютер должен быть включён утром)
В терминале одна команда (замените путь, если папка в другом месте):
```
(crontab -l 2>/dev/null; echo "0 8 * * * cd $HOME/my-company && /usr/bin/env python3 -m agents.secretary.run >> reports/cron.log 2>&1") | crontab -
```
`0 8 * * *` значит «каждый день в 8:00». Проверить: `crontab -l`. Убрать: `crontab -r`.
Если Mac спросит про доступ к папкам — разрешите. Папку держите в домашней папке, не на Рабочем столе: macOS не даёт расписанию доступ к Рабочему столу.

### Вариант Б. Windows (компьютер должен быть включён утром)
1. Пуск › «Планировщик заданий» › **Создать простую задачу**.
2. Имя: «Секретарь». Триггер: **Ежедневно**, 8:00.
3. Действие: **Запустить программу**.
   - Программа: `py`
   - Аргументы: `-m agents.secretary.run`
   - Рабочая папка: `C:\Users\<имя>\my-company`
4. **Готово**. Проверить: правой кнопкой по задаче › **Выполнить**.

### Вариант В. В облаке GitHub — компьютер может быть выключен (рекомендуем)
Нужна своя приватная копия на GitHub (шаг 3, второй способ).
1. На странице вашего репозитория: **Settings › Secrets and variables › Actions › New repository secret**. Добавьте три секрета:
   - `LLM_API_KEY` — ключ нейросети;
   - `TELEGRAM_BOT_TOKEN` — токен бота;
   - `TELEGRAM_CHAT_ID` — ваш chat id.
2. Для YandexGPT на вкладке **Variables** добавьте `LLM_BASE_URL`, `LLM_MODEL`, `LLM_FOLDER_ID`.
3. Вкладка **Actions** › **Secretary** › **Run workflow** — проверочный запуск. Через минуту сводка придёт в Telegram.
4. Дальше она будет приходить каждый день в 8:00 по Москве. Время меняется в файле `.github/workflows/secretary.yml`, строка `cron: "0 5 * * *"` (время по Гринвичу: Москва минус 3 часа).

Для приватных репозиториев GitHub даёт 2 000 бесплатных минут в месяц. Один запуск секретаря — меньше минуты.

Задачи можно править прямо на сайте GitHub: откройте `company/tasks.md` › значок карандаша › **Commit changes**. Хоть с телефона.

## 11. Если что-то не работает

| Что видите | Что значит | Что сделать |
|---|---|---|
| `command not found: python3` | Python не установлен | Шаг 2 |
| `No module named agents` | Вы не в папке компании | `cd ~/my-company` |
| `LLM_API_KEY is empty` | Нет ключа в `.env` | Шаг 4. Проверьте, что файл называется `.env`, а не `.env.txt` |
| `Model API error 401` | Неверный ключ | Скопируйте ключ заново, без пробелов |
| `Model API error 402` | Кончились деньги на балансе | Пополните баланс |
| `Model API error 429` | Слишком много запросов | Подождите минуту |
| `не удалось прочитать ленту` | Ссылка на ленту неверная или сайт недоступен | Откройте ссылку в браузере |
| Сводка не приходит в Telegram | Нет токена или chat id, или вы не написали боту | Шаг 9, пункты 5–6 |
| Сводка выдумывает | Мало данных или размытая инструкция | Проверьте `--dry-run`, уточните `prompt.ru.md` |
